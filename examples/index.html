Review formats separately. Open the standard report card and use the Content example selector to browse its pages. Content, branding, and TAC depth vary; they share one format.

Approve format and Request changes save decisions in this browser. Export writes a portable JSON receipt. To record those exact decisions in CRK, run just review-apply path/to/crk-format-review.json. No format is approved automatically.

Editing a format's examples, metadata, previews, or shared report styles makes its earlier review stale. Refresh the gallery and review again. Reference approvals describe the selected style; they do not approve an unbuilt CRK recipe.

Clone a starter with just example-new basic-report quarterly-review, edit examples/quarterly-review.html, then run just check and refresh. Swap an image with just preview-image quarterly-review path/to/preview.png.

The card layout and preview flow reuse the existing Expert Atlas Style Guide. examples/catalog.json owns the records. just export-style-guide creates the same gallery as a portable collection for that guide.
